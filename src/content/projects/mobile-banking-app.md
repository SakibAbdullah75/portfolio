## Overview

The mobile banking platform of a commercial bank, built with Flutter for both Android and iOS. I have been on the project since July 2024 and it is still in active development.

## What I did

- Refactored existing features, including migrating one feature's data layer
- Implemented token interceptors so authorised remote calls are handled in one place
- Integrated push notifications
- Wrote widget and unit tests for several features
- Automated iOS code signing and fixed the coverage calculation script in the pipeline
- Separated the production deployment flow from the test flow
